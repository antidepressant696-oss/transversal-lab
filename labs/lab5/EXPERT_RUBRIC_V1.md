# Lab 5 — Expert Rubric v1

Primary focus: reflexive-regulatory component.

For expert observation, record whether the student:
1. accurately distinguishes expected and actual results;
2. avoids treating an assumption as a verified cause;
3. uses participant feedback as evidence;
4. proposes an alternative strategy linked to the difficulty;
5. formulates a concrete next professional goal and transfers the learning to a new situation.

This is a draft observation rubric, not a validated psychometric scale. Numerical weights should be approved as part of the single diagnostic system for the dissertation rather than invented separately for this module.
