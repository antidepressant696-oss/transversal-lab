# Transversal Lab — Lab 4 / Scientific Matrix v0.1

## Purpose
Lab 4 is a focused digital-literacy case. It observes how a future primary-school teacher searches for digital information, checks reliability, selects a digital tool for a didactic task and critically evaluates an AI-generated result.

## Source basis
The dissertation materials define four components, including the **digital literacy component (raqamli savodxonlik komponenti)**. In the II–III chapter it is assessed through the criterion **“AKTdan foydalanish”** with indicators including **LMS, sun’iy intellekt vositalari, media savodxonligi, raqamli kontent yaratish**. The experiment also uses digital learning platforms, AI tools, electronic portfolios and formative assessment.

This Lab 4 is therefore a **digital case simulation**, not a claim that the current website itself is a validated diagnostic instrument.

## Task-to-evidence map

| Task | Observable action | Main component | Evidence | Status |
|---|---|---|---|---|
| 1. Start the search | Chooses an identifiable source instead of treating any first result or AI output as a verified source | Digital literacy | Source-choice + written justification | Observational |
| 2. Verify information | Cross-checks key facts with a reliable source | Digital literacy; supports cognitive | Verification-choice + written justification | Observational |
| 3. Select a tool | Chooses a simple visual tool because it fits the learning task and learner age | Digital literacy | Tool-choice + written justification | Observational |
| 4. Evaluate AI | Checks facts, language and age fit; revises before use | Digital literacy; supports reflexive regulation | AI-evaluation choice + written justification | Observational |

## Important limitation
The current website does not assign a final scientific score. A validated scale, thresholds, weights and reliability evidence must be approved for the full diagnostic system before any numerical interpretation is used in the dissertation.
