# Transversal Lab — Lab 4 v0.1

## What this module does
A self-contained multilingual interactive case focused on digital literacy in a primary-school teaching situation.

## Languages
- Русский
- O‘zbek (Latin)
- Ўзбекча (Cyrillic)
- English

## Run
Open `index.html` in a browser. No server is required.

## Scientific role
The case observes actions related mainly to the digital literacy component. It is not presented as a validated scoring instrument.

## Files
- `index.html` — interface
- `app.js` — logic and multilingual content
- `styles.css` — visual style
- `SCIENTIFIC_MATRIX.md` — task-to-evidence mapping
- `EXPERT_RUBRIC_V1.md` — working expert rubric
