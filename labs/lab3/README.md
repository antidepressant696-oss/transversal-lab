# Transversal Lab — Lab 3 v0.1

Lab 3 is the communication-focused module of the Transversal Lab prototype.

## Purpose
The case is designed around the social-communicative component from the dissertation materials: understanding a participant's position, active listening, adapting communication, asking clarifying questions, aligning positions, and reaching a constructive joint action.

## Languages
The interface is structured from the start for:
- Russian
- Uzbek (Latin)
- Uzbek (Cyrillic)
- English

The language switch changes the complete interface and case content without changing the underlying diagnostic logic.

## How to run
Open `index.html` in a browser. No server is required.

## Scientific caution
The profile is an evidence display, not a validated numerical score. Thresholds, weights and final scoring should be approved for the complete diagnostic system after all modules are aligned with the dissertation.
