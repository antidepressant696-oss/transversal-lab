# Transversal Lab — Lab 2 v0.4

Интерактивный педагогический кейс по теме развития трансверсальных компетенций будущих учителей начальных классов.

## В этой версии

- сохранена логика Lab 2;
- усилена связь кейса с 4-компонентной моделью диссертации;
- добавлено обязательное письменное обоснование цифрового выбора;
- автоматическая диагностика не присваивает научные баллы;
- сохранена отдельная научная матрица `SCIENTIFIC_MATRIX.md`;
- в профиле отображаются наблюдаемые источники доказательств, а не «оценка компетенции».

## Запуск

Откройте `index.html` в браузере.

## Научное ограничение

Lab 2 является цифровой средой предъявления и фиксации диагностических заданий. Один кейс не заменяет полную диагностическую систему диссертации и не дает оснований автоматически присваивать уровень сформированности компетенций.

- `EXPERT_RUBRIC_V1.md` — рабочая качественная рубрика для экспертного анализа открытых ответов.


## v0.5 diagnostic layer

Added a structured diagnostic record:
- observable responses are stored;
- evidence is mapped to indicator IDs;
- candidate indicators are explicitly marked as requiring expert review;
- the completed record can be saved locally and downloaded as JSON;
- no numerical scientific score is generated automatically.
