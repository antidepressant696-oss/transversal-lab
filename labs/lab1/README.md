# Transversal Lab — MVP v0.3

## Что изменилось
- Главный экран переведён из абстрактной графики в визуальную педагогическую ситуацию.
- Светлый спокойный интерфейс сохранён.
- На hero теперь сразу видно: 2 класс, групповая работа, конфликт, учитель и несколько наблюдаемых признаков.
- Главный сценарий продукта: ситуация → анализ → действие → диагностика → рефлексия.
- 4 компонента исследования сохранены: когнитивный, социально-коммуникативный, цифровая грамотность, рефлексивно-регулятивный.

Откройте `index.html` двойным кликом.
