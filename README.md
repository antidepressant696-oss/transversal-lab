# Transversal Lab — Unified v1.0-alpha

Это первая интеграционная оболочка проекта.

## Что сделано

- объединены Lab 1–5 в одной структуре;
- добавлен единый выбор языка на главной странице;
- подготовлен каркас будущего профиля студента;
- создана рабочая мастер-матрица научной трассируемости;
- существующие Labs не переписаны и не изменены.

## Важное правило

Четыре компонента не трактуются как четыре изолированные последовательности. У каждого Lab есть ведущий компонент, но отдельные задания могут давать свидетельства и по другим компонентам.

## Следующий этап

1. Согласовать единую диагностическую матрицу.
2. Определить, какие действия считаются доказательствами по каждому индикатору.
3. Только после этого подключать единую систему результатов и профиль студента.
4. Затем — кабинет преподавателя и хранение результатов.
