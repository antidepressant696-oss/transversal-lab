# Transversal Lab Unified v0.9 — Teacher Dashboard

Добавлен локальный прототип кабинета преподавателя: `teacher.html`.

Функции:
- список локальных результатов текущего браузера;
- импорт диагностических JSON-файлов;
- демо-студент для проверки интерфейса;
- сводка по Labs и свидетельствам;
- открытие профиля студента по 4 компонентам;
- общий переключатель языка через `tl_lang`.

Ограничение:
это ещё не многопользовательское хранилище. Реальные студенты между разными компьютерами/браузерами пока не синхронизируются. Для этого следующим этапом понадобится постоянное хранилище и авторизация.
