# Transversal Lab — Defense Demo

## Что получает комиссия

Одна публичная ссылка на `index.html`.

Без регистрации комиссия сможет:
- открыть лабораторию;
- пройти Lab 1–5;
- открыть «Мой профиль» и увидеть демонстрационные результаты;
- открыть «Кабинет» и увидеть демонстрационного студента.

## Важно

В демо-данных нет персональных данных. Это только пример структуры результатов.

## Перед защитой

1. Разместить содержимое папки в публичном GitHub-репозитории.
2. Включить GitHub Pages.
3. Проверить ссылку в режиме инкогнито.
4. Проверить с телефона.
5. На защите дать комиссии одну ссылку на `index.html`.

## Локальная проверка

Открыть `index.html`, затем проверить:
`Лаборатория → Мой профиль → Кабинет → любой Lab`.

При первом открытии профиль и кабинет уже содержат демонстрационные данные.
