# Transversal Lab Unified v1.2 — Navigation architecture

Навигация унифицирована на уровне всей системы.

В верхнем правом углу теперь одна понятная логика:

СТУДЕНТ → Лаборатория | Мой профиль
ПРЕПОДАВАТЕЛЬ → Кабинет | Язык

Названия не дублируются («Главная»/«Лаборатория», «Кабинет преподавателя»/«Кабинет»), чтобы пользователь однозначно понимал назначение ссылки.

На Lab 1 сохранена его собственная внутренняя навигация по разделам («Лаборатория», «Методика», «Компетенции», «О проекте»), но глобальные ссылки вынесены в правый верхний угол.

Lab 2 исправлен: удалена прежняя сломанная вложенная ссылка «Профиль/Главная».

Все глобальные подписи переключаются вместе с выбранным языком.
