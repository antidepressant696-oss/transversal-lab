# Transversal Lab Unified v1.3 — clear global navigation

Финальная логика верхней навигации:

СТУДЕНТ
- Лаборатория — вход в единую лабораторию и выбор Lab 1–5
- Мой профиль — персональный результат прохождения

ПРЕПОДАВАТЕЛЬ
- Кабинет — мониторинг результатов студентов

Справа — переключатель языка.

На активной странице соответствующая ссылка подсвечена.
Внутренние навигационные ссылки и повторяющиеся кнопки убраны, чтобы не создавать путаницу.

Таким образом, «Лаборатория» и «Мой профиль» относятся к студенту, а «Кабинет» — к преподавателю.
