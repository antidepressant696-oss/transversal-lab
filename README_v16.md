# Transversal Lab Unified v1.6 — Defense Demo

Добавлен публичный демонстрационный режим для защиты.

Главная идея:
**одна ссылка → комиссия открывает сайт → всё уже заполнено демонстрационными данными.**

Демо-данные:
- не содержат персональных данных;
- показывают прохождение Lab 1–5;
- заполняют «Мой профиль»;
- автоматически показывают демонстрационного студента в «Кабинете».

Демо-режим не заменяет реальное многопользовательское хранилище. Это безопасный публичный слой для демонстрации на защите.
